## Preferencias del usuario

- Las specs de un tema son alternativas: pueden ser juegos distintos o el mismo juego con distintas características, a criterio del agente.
- Siempre una recomendada, y es la `01`.
- Las specs quedan en `Borrador`; el usuario las revisa, las mueve a `specs/` y las aprueba.
- Si el tema coincide con una tarjeta simulada existente en `GAMES` (p. ej. `frog-crossing`), usar un id nuevo y no tocarla; dejarlo anotado en las decisiones.
- Evitar los nombres de juegos comerciales en títulos (p. ej. no usar FROGGER).
