## Preferencias del usuario

- La skin se elige con un `<select>` y se guarda en `localStorage` por juego.
- El agente solo escribe en la carpeta del juego y en `specs/` (la spec va junto a las demás).
- No hace commits.
- Le gustaron neon, pixel-art y classic de block-stack. Se probó retro ámbar multitono en asteroids, pero el usuario pidió volver al retro verde fósforo monocromo de block-stack (#33ff66/#1f9d3f sobre #020a02, scanlines 1px/3px): ese es el retro estándar para todos los juegos. Distinguir roles por brillo y forma (disparos cuadrados, trazos más gruesos), no por tono.
- Estructura usada: `skins.ts` (tipo + 4 skins + localStorage) y `skin-selector.ts` (select creado por el motor en `canvas.parentElement`, esquina inferior derecha, estilo en linea con tokens `var(--pixel)`, `var(--bg-2)`, `var(--cyan)`, `var(--line)`). En asteroids se añadió `skin-draw.ts` (trazo vectorial o en bloques en coordenadas de mundo, fuente, scanlines) y las entidades reciben `draw(context, skin)`.
- La fuente de canvas no acepta `var()`: leer `--font-press-start` con `getComputedStyle(document.documentElement)` en cada cuadro.
- Paletas ya usadas: reutilizar cian #00f5ff, amarillo #f5ff00, magenta #ff006e (neon) y #39ff14 verde / #ff8a00 naranja; pixel-art con #14122b, #41d6f5, #ffd23f, #ff9f43, #ff5964, #b45cff, #5be37d.
- Para fruit-snake el usuario pidió retro rosa/rojo (no verde, ámbar ni azul; azul reservado a wall-breaker) y una 5ª skin `experimental` (concepto distinto de synthwave, que usa wall-breaker). Si vuelve a pedirse, usar el mismo `id` `experimental` y documentarlo como Decisión.
- Shell: heredocs largos con python en Bash fallaron aquí; usar Write/Edit para editar archivos.
- Wall-breaker: el usuario pidió retro azul hielo y una 5ª skin `experimental` (synthwave); selector arriba a la derecha porque abajo tapa la paleta. Python no existe en el shell: editar en lote con node o Edit.
- Infraestructura global (SPEC 14, 2026-11-22): selector `<select class="skin-select">` en la barra del player (siempre habilitado, sin etiqueta), `setSkin` en el engine, `shared/skins.ts`, hook `use-stored-skin.ts` y `skin-registry.ts`. El engine no crea DOM ni lee localStorage. Referencia: asteroids y `.claude/skills/add-game/skins-guide.md`.
