# Arcade Vault

Es una plataforma para jugar online y competir por la mayor cantidad de puntos.

## Usa Spec Driven Design

Basado en /spec y /spec-impl

Siguiendo las buenas practicas recomendadas aquí:
https://github.com/Klerith/fernando-skills

## Skills usadas

```bash
npx skills@latest add Klerith/fernando-skills
```

## Comandos

- `npm run dev` — inicia el servidor de desarrollo (Turbopack)
- `npm run build` / `npm start` — compila para producción / sirve la compilación
- `npm run lint` — ESLint (configuración flat en `eslint.config.mjs`, `eslint-config-next`)
- Aún no hay ningún framework de pruebas configurado.
